Changelog
=========

1.0.0
-----

- WebSocket client for hxcpp, HashLink, Neko, eval and JavaScript with `wss://` support on native targets.
- `Client` with rooms, quick join, events, binary relay, state, player data, chat, host tools, latency and server clock.
- `Http` and `Leaderboard` helpers.
- Node.js server with rooms, relay, heartbeats, rate limiting, origin checks and JSON leaderboards.
